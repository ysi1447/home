PART 1 · ⌨️ 필수 단축키

⏱️ 시간을 아껴주는
3가지 필수 단축키

🖱️ 자주 쓰는 기능일수록 키보드와 마우스 조합으로 빠르게 처리하세요 ✨
1

📋 Ctrl + C / Ctrl + V

복사 · 붙이기

문자나 그림을 선택한 뒤 Ctrl+C로 복사하고, 원하는 위치에 Ctrl+V로 붙여넣습니다. 📎

2

🎤 Windows + H

음성 입력

타자를 치기 번거로울 때 윈도우 버튼 + H를 누르면 말로 편하게 글자를 입력할 수 있습니다. 🗣️

3

🔍 Ctrl + 마우스 휠

화면 조절

Ctrl 키를 누른 채 마우스 휠을 위로 올리면 화면이 커지고 👆, 아래로 내리면 작아집니다 👇

💡 더 알아두면 좋아요!
↩️ Ctrl+Z 실수했을 때 되돌리기
🔲 Ctrl+A 전체 선택   💾 Ctrl+S 저장
1️⃣ Ctrl+0 화면 크기 원래대로

PART 2 · ⭐ 크롬 즐겨찾기

🌐 크롬 새 탭에
바로가기 버튼 추가하기

단축키 Ctrl+C와 Ctrl+V를 그대로 활용하는 4단계 방법 🚀
1
1단계 🏁

원하는 사이트 이동

즐겨찾기 버튼으로 등록하고 싶은 웹사이트에 먼저 접속합니다. 🖥️

2
2단계 📋

주소 클릭 후 복사

화면 위쪽 주소창을 클릭한 뒤 Ctrl + C를 눌러 주소를 복사합니다.

3
3단계 ➕

새 탭 · 바로가기 추가

크롬의 새 탭(+)을 클릭한 후 '바로가기 추가' 버튼을 누릅니다. 👆

4
4단계 ✅

이름과 URL 입력

이름 칸에 사이트명을 적고, URL 칸에 Ctrl + V로 주소를 붙여넣습니다. 🎉

💡 알아두세요!
🔗 URL은 인터넷 주소(예: www.naver.com)를 뜻해요.
✏️ 바로가기를 고치거나 지우려면 버튼 오른쪽 위 점 3개(⋮)를 누르세요.
📌 자주 가는 사이트(은행·세금계산서·그룹웨어)를 등록해 두면 편해요!

PART 3 · 🎯 핵심 포인트

📁 다운로드한 자료는
어디에 저장될까요?

일반 다운로드와 카카오톡 다운로드의 저장 폴더가 다릅니다 ⚠️
⬇️

일반 다운로드 (크롬 · 웹 등)

  • 🌍 인터넷에서 내려받는 모든 자료의 기본 저장 위치
  • 📂 저장 경로: 파일 탐색기 안 '다운로드' 폴더
  • 📄 크롬에서 받은 문서, 사진, 프로그램 설치 파일 모두 포함
💬

예외: 카카오톡 다운로드

  • 🟡 카카오톡에서 받은 파일은 별도 폴더에 저장
  • 📂 저장 경로: 탐색기 안 '문서' > '카카오톡 받은 파일'
  • 🔎 카톡으로 받은 자료를 찾을 때는 문서 폴더부터 확인
💡 찾기 꿀팁!
📁 Windows+E 파일 탐색기 열기
⏬ 크롬에서 Ctrl+J 누르면 방금 받은 파일 목록이 나와요
🔍 못 찾겠으면 탐색기 오른쪽 위 검색창에 파일 이름을 입력!
